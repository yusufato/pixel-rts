## Kapsam

- yerel geliştirme ve test komutları;
- Electron paketleme ve model yerleşimi;
- uzun koşu, eğitim ve test tezgâhlarının işletimi;
- üretilmiş kayıtların konumu ve saklama sözleşmesi.
